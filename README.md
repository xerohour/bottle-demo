# bottle-demo

A Pocket demo: a pastel sea scene with a little bottle character and a
START THE DEMO screen.

- Source Pocket project: https://madewithpocket.com/p/FCS8fSr_b
  ("Demo — Armed with a makeshift bottle on his back…" by @aerdna)
- Live mirror: https://xerohour.github.io/bottle-demo/
- Single self-contained `index.html` (React app, 540 KB) plus 7 images
  under `assets/`, downloaded from the project's CDN links and localised
  so the page has no expiring external references. Sounds are synthesized
  in the browser with WebAudio; no server calls, no backend.
